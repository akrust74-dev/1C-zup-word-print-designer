# Конструктор печатных форм WORD/WRITER для ЗУП 3.1

Печать кадровых документов по собственным шаблонам MS Word / LibreOffice Writer: трудовые договоры, дополнительные соглашения, приказы, договоры ГПХ, договоры о полной материальной ответственности.

Внешняя обработка (`.epf`) для «Зарплата и управление персоналом 3.1». Текст документа живёт в Word — в нём расставляются теги вида `{v8 СотрудникИНН}`, обработка подставляет данные из документа и открывает готовый файл. Шаблоны хранятся в базе (`Справочник.Файлы`), правятся без конфигуратора, типовые печатные формы не затрагиваются.

**Версия:** 2.4 · **Проверено на:** платформа 8.5.1.1529, ЗУП 3.1.39.87 (и 3.1.29.62 / 8.3.2x)

---

## Зачем эта сборка

Старые версии этой обработки на новых релизах платформы перестают работать: вместо печати — «Значение не является значением объектного типа», пустой список макетов или кнопка, которая молча не нажимается. В релиз 3.1.39 код обработки компилируется и все общие модули БСП на месте — ломаются типы реквизитов и разметка формы.

Здесь — исправленная сборка: запускается, показывает макеты, заполняет шаблоны и печатает.

## Возможности

- список макетов прямо в форме, любое их количество на вид документа;
- документы: «Прием на работу», «Прием на работу списком», «Кадровый перевод», «Кадровый перевод списком», «Перемещение в другое подразделение», «Договор (работы, услуги)» (ГПХ);
- шаблоны `.doc`, `.docx`, `.odt`, печать через MS Word или LibreOffice на клиенте;
- таблица подстановок на экране: до печати видно, каким значением заполнится каждый тег;
- склонение ФИО по падежам, вариант «Фамилия И. О.»;
- суммы числом и прописью, даты числом и прописью («22 сентября 2026 г.»);
- шаблоны версионируются штатным механизмом БСП — правка макета не требует новой версии обработки;
- работает под обычными правами кадровика.

## Установка

1. Скачать `.epf` из папки [`epf/`](epf).
2. ЗУП: **Администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
3. **«Добавить из файла…»** → выбрать `.epf`.
4. В карточке: вид — «Печатная форма», размещение — «Использовать», назначение — список документов.
5. **Записать и закрыть**, на запрос «Разрешить открывать файл?» — «Да».
6. Проверка: «Прием на работу» → **Печать** → «Конструктор печатных форм WORD/WRITER».

Менять файл у зарегистрированной обработки — через карточку, кнопкой **«Заменить файл»** (не подкладывать `.epf` в папку на диске и не добавлять запись заново).

## Шаблоны

Хранятся в информационной базе:

```
Файлы → «Шаблоны файлов»
   ├── «Прием на работу»            ← ТД, доп. соглашения, приказы, ПМО
   └── «Договор (работы, услуги)»   ← договоры ГПХ
```

- добавить: кнопка «Изменить макет» при пустом выделении либо Файлы → папка → «Добавить файл»;
- заменить: открыть файл → «Заменить файл» → «Обновить макеты» в форме;
- имя файла = строка в списке макетов.

Требования к шаблону:

- `.doc`, `.docx`, `.odt`;
- теги `{v8 ИмяТега}` — фигурные скобки, латинские `v8`, пробел, имя; регистр важен;
- **основной текст должен заканчиваться тегом `{/v8 Область.Общая}`** — по нему механизм офисных макетов БСП определяет границу области; в колонтитулах он не нужен;
- теги можно ставить в тексте, таблицах, колонтитулах; разрыв тега форматированием Word подстановке не мешает.

В папке [`templates/`](templates) лежат четыре готовых шаблона: бессрочный ТД, срочный ТД, договор о полной материальной ответственности, договор ГПХ.

## Теги

Полный список с примером заполнения — [`docs/`](docs) (файл «Теги конструктора печатных форм (список).docx»).

Сокращённо:

- **документ:** `ДокументНомер`, `ДокументДата` (+`_`), `ДокументГод`, `ДокументСотрудника`, `ДокументРуководитель` (+`_РП`/`_ДП`/`_ВП`/`_ФИО`), `ДокументРуководительДолжность` (+`_РП`);
- **договор:** `ДоговорНомер`, `ДоговорДата` (+`_`), `ДоговорДатаНачала` (+`_`), `ДатаНачала`/`ДатаОкончания` (+`_`), `ДоговорСумма` (+`_`), `СпособОплаты`, `РазмерПлатежа`;
- **организация:** `ОрганизацияНаименованиеПолное`, `ОрганизацияНаименованиеСокращенное`, `ОрганизацияИНН`, `ОрганизацияКПП`, `ОрганизацияОГРН`, `ОрганизацияКодПоОКПО`, `ОрганизацияКодОКВЭД2`, `ОрганизацияЮридический_адрес`, `ОрганизацияПочтовый_адрес`, `ОрганизацияРайонныйКоэффициент`, `ОрганизацияПроцентСевернойНадбавки`, `ОрганизацияТелефон`, `ОрганизацияEmail` и др.;
- **сотрудник:** `Сотрудник`, `Сотрудник_ФИО`, `Сотрудник_РП`/`_ДП`/`_ВП`, `СотрудникФамилия`, `СотрудникИмя`, `СотрудникОтчество`, `СотрудникДатаРождения` (+`_`), `СотрудникПол`, `СотрудникИНН`, `СотрудникСНИЛС`, `СотрудникПаспортныеДанные`, `СотрудникАдрес_по_прописке` (+`_`), `СотрудникМобильный_телефон` (+`_`), `СотрудникДолжность`, `Должность`, `ДолжностьПоШтатномуРасписанию`, `Подразделение`, `Оклад`, `СовокупнаяТарифнаяСтавка`, `ВидТарифнойСтавки`, `ДатаПриема` (+`_`), `КоличествоСтавок`, `ВидЗанятости`, `ГрафикРаботы`, `УсловияПриема`, `Территория`, `ДатаЗавершенияТрудовогоДоговора` (+`_`), `ОтпускОсновной`, `ОтпускСеверный`, `Ответственный`, `Комментарий`;
- **руководитель:** `Руководитель`, `Руководитель_РП`/`_ДП`/`_ВП`, `Руководитель_ФИО`, `РуководительНаименование` (+`_РП`), `РуководительПол`, `ДолжностьРуководителя` (+`_РП`);
- **начисления:** `Начисление<ИмяНачисления>` — сумма, `…_` — прописью, `…Показатель` — показатель; итог `НачислениеВсего` (+`_`).

Правила имён: `_` — то же значение в текстовом виде; `_РП`/`_ДП`/`_ВП` — падежи; `_ФИО` — «Фамилия И. О.»; `Показатель` — размер/процент, а не сумма.

## Ограничения

- нужен MS Word 2007+ или LibreOffice на машине пользователя (на сервере офис не требуется);
- у обработки должен быть **выключен** безопасный режим;
- шаблоны лежат в базе — поправить файл «на диске» нельзя, только через интерфейс ЗУП;
- переименовали вид начисления — изменилось имя тега, шаблон в этом месте перестанет заполняться;
- отсутствующие в релизе реквизиты просто не попадают в набор, обработка не падает;
- должность руководителя выводится, только если заполнена в «Основаниях полномочий ответственных лиц».
