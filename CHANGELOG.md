# Changelog

Все изменения — по обработке «Конструктор печатных форм WORD/WRITER для ЗУП 3.1».
Версия видна в карточке дополнительной обработки в ЗУП.

## 2.4 — должность руководителя организации

- Новые теги `{v8 ДолжностьРуководителя}` и `{v8 ДолжностьРуководителя_РП}`.
- Значение берётся из регистра «Основания полномочий ответственных лиц»: в ЗУП 3.1 должность директора не хранится ни в карточке организации, ни в «Ответственных лицах» (там только физлицо). Запрос отбирает запись по физлицу руководителя на момент документа и учитывает дату окончания полномочий.
- Теги собираются в общем блоке данных, поэтому доступны во всех документах, включая договор ГПХ, где раньше подписант не выводился никак.

## 2.3 — убрана диагностика

- Удалено модальное окно «Кнопка нажата» (стояло в 1.9–2.2 для поиска причины неработающей кнопки).

## 2.2 — исправлена коллизия id элементов формы

- У кнопки «Изменить макет» и её подсказки были `id` 110 и 111 — такие же, как у контекстного меню таблицы макетов и его подсказки. При загрузке формы кнопка привязывалась не к команде: рисовалась, но клик никуда не уходил, без сообщений об ошибке.
- Свои элементы перенумерованы в свободный диапазон (кнопка 900, подсказка 901, команда 902).

## 2.1 — убрана старая кнопка на глобальную команду

- Из панели макетов удалён `<Button>` с `CommandName` вида `0:<uuid>` (глобальная команда ЗУП). На 3.1.39 она либо исчезает, либо остаётся видимой и выглядит точно как новая кнопка — пользователь жмёт её, и «ничего не происходит».
- Своя кнопка получила явный заголовок «Изменить макет», чтобы её нельзя было спутать.

## 2.0 / 1.9 — диагностика кнопки

- Обработчик собран так, чтобы не «глотать» ошибки: накапливает тексты исключений и показывает их одним сообщением.
- В 1.9 первой строкой стояло `Предупреждение("Кнопка нажата")` — так были разделены две разные причины: не вызывается команда или не открывается форма файла. В 2.3 окно убрано.

## 1.6 — кнопка «Добавить, изменить макет»

- Возвращена кнопка правки макета из формы: открывает карточку выбранного файла-шаблона (там «Заменить файл»), при пустом выделении — список файлов, иначе — карточку папки макетов.
- Исправлен поиск папки: раньше искалась только по имени типа (`ДокументСсылка.ПриемНаРаботу`), а в базах папку называют по-людски — «Прием на работу». Теперь ищется по обоим вариантам на любом уровне иерархии.
- Исправлено присвоение ссылки при создании папки: присваивалась ссылка пустой папки вместо только что созданной.
- `ПапкаФайлов` переведён из «Строка(10)» в `СправочникСсылка.ПапкиФайлов`.

## 1.2 — типы реквизитов-ссылок

- `СсылкаНаОбъект` объявлен как `v8:AnyRef` вместо `xs:string(10)`. На платформе 8.5 строковое поле не даёт вызывать `.Метаданные()` — обработка падала при открытии из документа («Значение не является значением объектного типа (Метаданные)»).
- Тем же исправлением переведены `Сотрудники.Сотрудник`, `Макеты.Макет`, `Макеты.ТекущаяВерсия`.

## 1.1 — имена тегов

- Наименования начислений попадали в имя тега как есть: «Оплата по окладу (по часам)», «Доплата, 20%», «№ 3». `Структура.Вставить` требует допустимый идентификатор — печать падала с «Задано неправильное имя атрибута структуры».
- Добавлен санитайзер: все символы вне `[A-Za-zА-Яа-я0-9_]` заменяются на `_`, если имя начинается с цифры — добавляется префикс `Т_`.

## 1.0 — базовая сборка

- Оригинальная обработка «Конструктор печатных форм для ЗУП 3.1 по шаблонам MSOffice и OpenOffice» (автор — Александр Забалуев, https://infostart.ru/1c/tools/693989/), компилируется на 3.1.39.87 без изменений.
- Прочее в этой сборке: колонка «Значение» расширена до 1000 символов (адреса и суммы прописью обрезались на 200).
